# Smoke_test_Selenium-Python
*The repository contains a pet project for a smoke test for buying a product on the website with board games [znaemigraem.ru](https://tomsk.znaemigraem.ru/).
It includes two test suites: 
-	a test for an unauthorized user;
-	a test for an authorized user.
This project is created with the Selenium framework using Python language. Each test suite includes all the steps for buying a board game with specific characteristics except a final step with order confirmation (as I am not ready to buy the game, just practice :smiley:). *
